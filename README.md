# UrbanMobility

**Objetivo:** evaluar cómo la movilidad urbana se relaciona con la productividad económica en las principales ciudades latinoamericanas. 

**Base de Datos:** datos reales de TomTom Traffic Index y OECD Cities, 

**Estructura:**
- limpiar
- combinar
- analizar

Identificación de qué ciudades conviene invertir en infraestructura de transporte.
